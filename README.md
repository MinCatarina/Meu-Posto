# Meu Posto

**Aluna:** Yasmin Catarina de Lima - RM569935

**Deploy:** https://mincatarina.github.io/Meu-Posto/

Protótipo CitizenTech para idosos que vão ao posto de saúde sem saber se o remédio está em estoque nem quais documentos levar. 

Jornada: escolher o remédio → ver postos e estoque → separar documentos e agendar → receber protocolo.

ODS 3 – Saúde e Bem-Estar. Dados simulados em `data.js`.
